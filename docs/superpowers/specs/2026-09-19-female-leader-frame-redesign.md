# 女领导 32 帧风格重构

## 状态

已由用户确认，待规格审阅。

## 目标

女领导整体对齐当前男领导的最新 32 帧像素视觉体系，同时保留其长发、眼镜、青绿色女装和喝咖啡待机动作。改造范围覆盖从正常到求饶终态的全部五个受击阶段。

## 非目标

- 不替换或重新绘制已经确认的男领导 32 帧素材。
- 不改变受击进度、武器、对话气泡或会话状态规则。
- 不仅给当前拆件叠加描边或伤痕；女领导需要完整帧组，而非局部修饰。

## 素材设计

- 新增 `assets/art/female_frames/female_00.png` 至 `female_31.png`。
- 画布尺寸、透明边界、帧顺序和动作语义与 `male_frames` 对齐：待机与喝咖啡、受击反应、各伤势保持帧，以及完整下跪终态。
- 每一帧采用男领导的姿态和构图作为动作模板，但重新绘制女领导本身；不得把男领导的脸、发型、体型或服装直接套用到女领导。
- 使用同一套紧凑 Q 版比例、深色粗描边、高对比阴影和强烈表情节奏。长发、眼镜、青绿色女装和咖啡是不可丢失的女领导识别点。
- 伤势从轻微到重伤逐级增加；终态显示衣物破损、头发凌乱、鼻青脸肿与完整下跪姿态，并配合现有散架桌椅。

## 运行时设计

- 将男领导的帧加载、按阶段选帧、统一基线、缩放补偿和桌后分层抽取为男女共用的帧角色路径；现有男领导画面和行为必须保持不变。
- 女领导的常规阶段采用同一桌后层次：上身在桌后，桌面与键盘在中层，柜体遮住腰部以下。喝咖啡帧可显示抬杯动作，但不得破坏桌沿遮挡。
- 求饶终态关闭常规坐姿裁切，显示完整女领导下跪帧、散架桌椅和飞散道具。
- 女领导原有的分件资源仅在迁移完成前保留，不再作为常规渲染路径；迁移不改变男领导资源引用。

## 验收与测试

- 所有 32 个女领导帧均可加载，且帧选择覆盖待机、喝咖啡、受击、伤势保持和终态。
- 五个受击阶段中的女领导头部、肩部和胸口在桌后稳定显示；柜体不透出腰部或腿部像素。
- 喝咖啡与攻击动画保持桌面、键盘、显示器和道具的正确层级；可见角色像素仍能命中，家具与道具仍会拦截命中。
- 求饶终态显示完整下跪女领导与损坏家具。
- 更新运行时画廊截图，人工确认女领导与当前男领导处于同一视觉语言和表现密度。
- 先新增会在旧女领导分件路径上失败的视图回归测试，再实现；随后运行核心、桌面和视图测试。若涉及导出，再运行完整构建及新解压启动检查。

## 取舍

以男领导帧作为姿态模板比给旧女领导局部加深描边工作量更大，但能保证动作密度、桌后构图和受击递进一致；重新绘制而不是直接修改男帧，避免女领导丢失独立身份。
