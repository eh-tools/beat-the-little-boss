# 男领导与办公桌融合

## 目标

让男领导在正常、轻微受伤、明显受伤和重伤阶段看起来坐在办公桌后。抽屉和桌脚之间不再透出精灵的下半身，同时保留头部、肩部、桌面上的手、抽烟动作和所有受击反馈。

## 设计

`PetView` 的男领导精灵继续使用现有 32 帧纹理和现有 hip 骨骼附件。常规阶段启用 `Sprite2D` 的 region，取原始 160×180 纹理的上方 160×108 区域；桌子仍在精灵之后创建并绘制为完整前景，因此桌沿成为人物的可见边界。该 region 不更改纹理、帧调度、骨骼回弹或武器层。

求饶终态关闭 region。该终态需要完整的下跪精灵与破损桌椅，不能被完整桌沿裁掉。

## 验证

视图回归测试覆盖：

- 男领导的正常阶段启用 160×108 的桌沿 region。
- region 外的桌下坐标不能命中男领导精灵。
- 求饶终态关闭 region，完整显示跪下帧。
- 原有的待机、抽烟、受击、伤势帧和前景命中测试继续通过。

导出后运行现有 Windows 启动探针，并生成新的便携包供实际视觉验收。
