# 打工人解气桌宠：Windows 便携版规格

状态：已综合访谈确认的产品需求；测试边界待用户确认；尚未发布到项目 issue tracker。

## Problem Statement

打工人希望在工作桌面上获得随手可玩的解气体验：用夸张的卡通武器点击虚构领导，看到其从装腔作势逐渐服软。体验需要有清楚的动作、外观、家具破坏和台词反馈，同时体积小、不妨碍日常桌面操作。

只有点击计数、重复抖动或占位素材不足以满足需求。用户要求直接以最终品质制作原创 Q 版像素角色，并交付能够完整玩一轮的 Windows 桌宠。

## Solution

提供基于 Godot 4 的 Windows 10/11 便携版桌宠。男、女领导坐在办公桌后的椅子上，分别抽烟、喝咖啡，偶尔冒出文字气泡。鼠标悬停显示当前武器，点击领导触发左右交替的普通击打或专属暴击。

每位领导有独立的 36 点受击进度。普通击打增加 1 点，暴击增加 2 点；随阶段推进，领导鼻青脸肿、服装破损、头发凌乱，台词逐渐服软，最终桌椅散架并下跪求饶。终态允许继续小幅受击，用户通过右键菜单同时恢复两位领导，开启下一轮。

主体初始显示约 160×180，气泡向上独立扩展。桌宠默认置顶、透明、可拖动，保留任务栏入口。语录、音效和缩放等设置仅存本机；受击状态只在本次运行中保留。所有台词均为文字，无语音朗读。

## Implementation Decisions

### 平台与交付

- 使用 Godot 4；延续已有架构决策，由同一运行时承载动画、交互、设置界面和 Windows 导出。
- 交付 Windows 10/11 便携版压缩包，解压运行。第一版不包含安装程序。
- 支持多显示器，初次出现在主屏右下角，后续恢复保存的位置。超宽屏和远程桌面不作为专项适配或验收目标。
- 启动立即显示桌宠。开机自启默认关闭；访谈早期接受自启开关，后期接受便携版先行、稳定后增加自启注册。按后者收敛：首个便携版不将自启注册列为验收项，后续再提供实际可用开关。

### 窗口与输入

- 无边框、透明、默认置顶、可拖动；保留任务栏入口，以及隐藏、显示、退出操作。
- 主体基准显示约 160×180，包含领导、办公桌和椅子；气泡不计入该尺寸，可向上扩展。提供 1 倍、1.5 倍、2 倍缩放并记住选择。
- 透明背景区域允许点击下方桌面或应用。气泡和特效不能把整个窗口矩形变成阻挡桌面的点击区域。
- 鼠标悬停桌宠时显示当前武器，并高亮可击打目标；离开后恢复正常指针。领导本身不会变成武器。
- 点击领导有效命中区域才触发攻击和增加进度；办公桌、椅子及透明区域不累计受击进度。桌椅可有轻微反馈，不属于必需攻击入口。
- 拖动与攻击必须区分。实施默认：按下并移动超过拖动阈值视为移动桌宠，不触发攻击；未构成拖动的点击才形成攻击请求。阈值通过实际操作微调。
- 右键菜单提供角色切换、武器切换、缩放、语录设置、音效控制、全部恢复正常、隐藏和退出；隐藏状态仍有可恢复入口。
- 数字键 1 选择大锤，2 选择双拳套。实施默认：仅在桌宠获得键盘焦点时生效，不劫持其他应用输入。

### 原创视觉与动画

- 最终目标为原创 Q 版像素风；允许网络视觉参考，交付素材需形成独立原创设计，不直接复制参考作品。
- 两位领导均需完整可玩，男领导可先用于打通制作流程，但第一版不能以只有男领导或占位素材交付。
- 男领导：中年、发际线后移、白衬衫、领带、西裤和皮带，待机抽烟；台词偏加班与甩锅。
- 女领导：中年短发、职业西装、夸张眼镜或耳环，待机喝咖啡；台词偏催进度与画大饼。
- 办公场景包含显示器、键盘、文件、咖啡杯和烟灰缸。小尺寸下须优先保证领导面部与武器轮廓可辨识。
- 身体、手臂、腿和武器使用真实 2D 骨骼动画；脸部表情、伤势、衣服破损和家具状态使用像素图层替换。两位角色可复用动作结构，保留各自造型、表情与演出区别。
- 使用统一像素比例和色板。骨骼旋转、缩放及图层切换需实际检查，避免像素边缘模糊、部件接缝和明显穿插；1.5 倍缩放需单独观察可读性。
- 每次有效击打呈现短暂姿态、表情或特效变化；长期外观按阶段切换，不要求为 36 个数值逐个制作完整独立造型。

### 武器、节奏与暴击

- 大锤为充气锤风格，普通攻击左右交替锤击，暴击向下砸并呈现头顶起包。
- 双拳套普通攻击左右交替摆拳，暴击为上勾拳并呈现下巴肿大。
- 普通攻击方向自动交替，暴击插入专属动作。实施默认：暴击不消耗普通攻击左右交替顺序。
- 每次实际执行的有效攻击以约 15% 概率触发暴击；若连续四次有效攻击未暴击，第五次必定暴击，出现暴击后重新计保底。空点击、溢出队列的点击不计保底，也不增加进度。
- 普通击打增加 1 点，暴击增加 2 点，进度上限为 36；越过上限时钳制到 36，仅触发一次终态演出。
- 当前动作期间最多排队两次攻击请求，额外点击忽略；排队不是立即结算进度。实施默认：切换角色、重置或退出时清空未执行请求，避免旧点击作用于新角色或新一轮。
- 普通攻击约 0.35 秒，暴击约 0.7 秒，受击停顿目标约 0.15–0.25 秒；作为可试玩调整的节奏基准，避免连点手感僵硬。
- 暴击包含短暂震动、撞击闪光、星星或冲击波及“暴击！”文字。实施默认：震动限定于桌宠演出区域，不移动用户桌面或其他应用。
- 求饶终态继续点击只作小幅反馈，进度维持 36，不循环播放桌椅散架。

### 受击阶段与场景演出

| 累计受击进度 | 受击阶段 | 长期外观和家具 | 台词态度 |
| --- | --- | --- | --- |
| 0–8 | 正常 | 完整外观和桌椅；仍有每次受击的瞬时反馈及暴击局部效果 | 装腔、训人、推卸责任 |
| 9–17 | 轻微受伤 | 轻微鼻青脸肿，物件可晃动或掉落 | 抱怨、质问、嘴硬 |
| 18–26 | 明显受伤 | 明显淤青，衣服开始破损 | 慌张，开始求停 |
| 27–35 | 重伤 | 头发凌乱，服装进一步破损，桌椅开裂并开始散架 | 明显服软，承诺不再加班甩锅 |
| 36 | 求饶终态 | 桌椅完全散架，衣服破烂，鼻青脸肿，下跪求饶 | 道歉和求饶 |

- 阶段根据累计进度计算；暴击可能从 8 直接到 10，不能依赖恰好等于 9 才触发阶段。
- 同次运行中两位领导的进度与外观独立保存，切换时恢复其对应状态。
- 重置同时恢复两位领导，不提供仅重置当前领导的第一版操作；重置不删除自定义语录或偏好。
- 每次新启动两位领导均从 0 点、完整家具与初始态度开始；首次角色默认男领导，之后显示上次选择的角色。

### 气泡、语录与音效

- 所有台词均为文字气泡，不播放台词语音，也不朗读自定义语录。
- 待机每 10–15 秒随机出现气泡，持续 2–3 秒；实际击打立即显示对应受击台词。实施默认：以实际攻击执行/命中作为受击气泡触发点，排队点击不提前冒泡。
- 连续受击使用单个气泡并限制刷新频率，不堆叠多个气泡；受击气泡优先于待机气泡。刷新间隔在试玩时微调，不需用户配置。
- 气泡自动换行，最多两行，每行约 12 个中文字符。实施默认：编辑或导入时对超长条目提示修改，不静默裁掉用户保存的文字；渲染按实际字宽控制，不能仅按字节数判断。
- 语录按男、女领导分别管理待机、受击、求饶三类，每类支持多条随机轮换。受击台词随五个阶段逐渐服软。
- 为衔接三类编辑入口与五阶段语气，实施默认：待机和受击条目可指定适用阶段，求饶条目用于终态；未指定阶段的自定义条目视为通用，不强制用户写满每个阶段。
- 支持新增、编辑、删除、恢复默认和保存，提供文本文件导入导出。实施默认：导入导出保留角色、类别与阶段信息；非法或超长内容应给出具体错误，不损坏已有台词。
- 没有可用自定义条目时回退到内置阶段语录，避免空台词导致互动中断。
- 短音效采用轻松搞笑的 8-bit/卡通风格，区分锤击、拳击、暴击和桌椅散架；默认低音量，右键可关闭音效并调节音量。

### 状态与本地设置

- 会话状态：两位领导各自的受击进度、伤势及家具表现，以及攻击队列等临时状态；退出后不保留。
- 本地偏好：自定义语录、上次角色选择、窗口位置、缩放和音效设置等；关闭后继续保留。
- 第一版按便携式配置设计，将配置保存在应用目录的本地配置文件中，不使用账号、云同步或上传。
- 实施默认：应用目录不可写时清楚提示无法保存，不假装保存成功；配置损坏时允许恢复默认，并尽量保留原始文件以便恢复语录。
- 显示器布局变化时，保存位置若已在屏幕外，应回到可见区域；按实际屏幕工作区域限制拖动与气泡展示。

### 逻辑责任划分

- 桌面交互负责透明窗口、命中、拖动、快捷键、菜单和位置；生成用户动作交给玩法流程。
- 玩法流程统一负责角色状态、攻击排队、暴击保底、阶段转换、终态与重置，形成主要行为测试入口。
- 角色演出根据玩法结果驱动骨骼、图层、家具、气泡和音效；不在动画脚本中另行累计伤势。
- 语录与偏好负责本地读写、内容校验及导入导出。采用简单清楚的模块边界，不为未来平台或武器引入通用框架。

## Testing Decisions

- 测试边界提案：以桌宠用户操作的完整流程为最高层入口，集中验证角色选择、命中、攻击推进、队列、阶段、重置和设置保存；Windows 窗口行为、动画和音效另以实际运行验收。该边界已向用户请求确认，尚未获得回复。
- 当前仓库只有领域术语和架构决策，无代码、测试框架或既有测试先例；不声称已有可复用测试。实现时围绕上述玩法入口建立尽量少的测试接口。
- 好的测试验证可观察行为，不断言具体私有字段、节点层级或每个动画关键帧。随机数和时间可控，以稳定验证概率分支与计时边界，而非用大量随机点击猜测正确性。
- 自动验证普通攻击加 1、暴击加 2、跨过 9/18/27 的阶段变化、35 点暴击到 36 的封顶及终态只进入一次。
- 自动验证暴击随机分支、连续四次普通攻击后的第五次保底、暴击后保底重置；未命中和未入队点击均不改变进度或保底。
- 自动验证最多两次待执行攻击、溢出点击忽略、队列按执行结算，以及切换/重置后旧队列不泄漏。
- 自动验证两位角色状态独立、全部重置都归零、重新启动伤势不恢复，同时自定义语录和偏好仍保留。
- 自动验证待机气泡出现间隔与显示时长的边界、受击优先、连续点击不累积气泡、五阶段台词筛选和空条目回退。
- 自动验证语录新增/编辑/删除/恢复默认、导入导出往返、超长内容和无效文本拒绝、保存失败的可见提示；测试使用临时配置位置，不覆盖用户真实语录。
- Windows 实测透明和置顶、桌宠外点击穿透、拖动不误击、武器指针进出恢复、隐藏后能恢复、快捷键焦点范围，以及多显示器位置和三档缩放。
- 美术验收以 160×180 实际尺寸为主，同时检查放大显示；确认角色可辨、像素一致、骨骼无明显接缝、两种武器动作可辨、局部暴击伤势可见、桌椅散架和下跪完整、气泡不裁切、声音开关有效。
- 必须执行完整一轮验收：启动 → 两位领导待机 → 切换角色和武器 → 普通攻击与暴击 → 各阶段外观及台词变化 → 36 点散架求饶 → 终态继续点击 → 一次重置两位 → 编辑并导入导出语录 → 退出重开，确认伤势归零而设置保留。

## Out of Scope

- macOS、Linux、移动端、网页版产品及云服务。

- 账号、联网生成台词、云同步、遥测上传。

- 36 套逐点独立完整造型；每击短暂反馈仍属范围内。
